# **App Name**: Planiverse

## Core Features:

- User Authentication: User authentication with email/password and Google login.
- Organization and Team Management: Organization and team creation to manage users and plans.
- Plan Management: Plan creation with public/private visibility settings and role-based access control (Admin, Editor, Viewer).
- Theming: Theming setup for organization branding (logo, colors).

## Style Guidelines:

- Primary color: HSL 210, 70%, 50% - A vibrant, deep sky blue (#3399FF) that conveys trustworthiness and innovation.
- Background color: HSL 210, 20%, 95% - A very light desaturated blue (#F0F8FF) for a clean, airy feel.
- Accent color: HSL 180, 70%, 50% - A lively cyan (#33FFFF) to highlight interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, and readable UI.
- Use minimalist, outline-style icons for a clean and modern aesthetic.
- Employ a card-based layout to organize plans and teams, promoting easy navigation.
- Incorporate subtle transitions and animations to provide feedback on user interactions.
